# AI提问与筛选系统

问得准，筛得严。一个装在手机上的小App：提问七招、筛选七关、每日练习、判断底稿。

## 功能

- **速查**：14招一屏看完，每招旁边显示掌握程度
- **提问**：填约束条件，自动拼好提示词，可以存进记录
- **练习**：每天3题，按遗忘规律复习，42道改写题和判断题
- **方法**：每招的完整教程、例子和模板，支持外贸、生意、生活、人生四种场景
- **工具**：信息体检（一次过七关）和小实验样本计算器
- **记录**：判断底稿和提问记录，支持搜索、筛选、复盘、导出备份

## 发布到 GitHub Pages（只用网页，不用装任何软件）

1. 登录 GitHub，点右上角 **+** → **New repository**，名字填 `tiwen`，选 **Public**，点 **Create repository**。
2. 在新仓库页面点 **uploading an existing file**，把这个文件夹里的所有文件拖进去，点 **Commit changes**。
3. 进入仓库的 **Settings** → 左侧 **Pages** → Branch 选 `main`、文件夹选 `/ (root)` → **Save**。
4. 等一两分钟，页面顶部会出现网址，形如 `https://你的用户名.github.io/tiwen/`。

## 装到手机

- **iPhone**：用 Safari 打开网址 → 分享 → 添加到主屏幕
- **安卓**：用 Chrome 打开网址 → 页面里的“安装到手机”按钮，或浏览器菜单 → 安装应用

## 数据说明

所有记录只保存在你自己的手机浏览器里，不上传到任何服务器。换手机或清理浏览器数据前，请在“记录”页点 **导出备份**，到新手机上再 **导入备份**。

## 更新App

改了 `index.html` 之后，把 `sw.js` 第2行的 `tiwen-v1` 改成 `tiwen-v2`（每次加1），再上传。手机上关掉App重新打开两次，就会换成新版本。
